HU03 — Consultar a contratação

História: Como cliente da Bulbe Energia, quero consultar as informações da minha contratação para confirmar qual serviço está associado a mim e esclarecer eventuais dúvidas sobre meu vínculo com a empresa.

Oportunidade de origem: #[número da Issue da oportunidade]

Critérios de aceite:

* [ ]	A tela deve apresentar as informações de contratação disponíveis.
* [ ]	Deve exibir os dados de identificação do contrato ou da adesão, quando disponíveis.
* [ ]	A tela deve explicar em linguagem simples qual serviço está associado à contratação.
* [ ]	Quando houver um documento contratual disponível, o cliente deve conseguir acessá-lo.
* [ ]	As condições apresentadas devem corresponder às informações disponíveis, sem inventar termos contratuais.
* [ ]	Caso alguma informação não esteja disponível, a tela deve informar essa limitação.
* [ ]	Deve existir uma orientação para buscar atendimento caso o cliente não reconheça a contratação ou encontre divergências.

Indicador que pretende mover: churn do 1º mês.

Tela relacionada: Minha contratação.
