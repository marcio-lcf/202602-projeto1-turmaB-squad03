# HU01 — Entender os valores e a economia

**História:** Como cliente da Bulbe Energia, quero visualizar os valores cobrados e entender como a economia foi calculada para comparar o benefício obtido com o que foi apresentado na contratação.

**Oportunidade de origem:** #[número da Issue da oportunidade]

**Critérios de aceite:**
- [ ] A tela deve exibir os valores das cobranças e seus respectivos períodos de referência.
- [ ] A tela deve apresentar o valor de referência sem o serviço, quando esse dado estiver disponível.
- [ ] A tela deve explicar de forma simples como a economia foi calculada.
- [ ] A tela deve diferenciar a economia estimada da economia efetivamente apurada.
- [ ] A tela não deve apresentar descontos ou valores que não sejam sustentados pelos dados disponíveis.
- [ ] Caso faltem dados para calcular a economia, a tela deve informar isso claramente.

**Indicador que pretende mover:** pagamento da 1ª fatura.

**Tela relacionada:** Resumo de cobranças e economia.
