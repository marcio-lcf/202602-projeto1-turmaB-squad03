# Histórias de usuário

## Dor priorizada

Dificuldade potencial dos novos clientes em compreender a primeira fatura e encontrar as informações necessárias para realizar o pagamento.

**Dado de contexto:** 32,4% de inadimplência na primeira fatura, conforme os dados fornecidos pela Bulbe Energia.

**Indicador:** percentual de inadimplência na primeira fatura.

## Histórias de usuário

| ID | História | Oportunidade de origem | Prioridade | Issue |
|---|---|---|---|---|
| HU01 | Como novo cliente da Bulbe Energia, quero visualizar o valor total e a data de vencimento da minha primeira fatura, para saber quanto devo pagar e até quando. | Compreensão da fatura | Alta | A definir |
| HU02 | Como novo cliente, quero consultar instruções claras de pagamento, para saber como pagar minha primeira fatura corretamente. | Orientação para pagamento | Alta | A definir |
| HU03 | Como novo cliente, quero acompanhar as etapas do meu processo de adesão, para saber em que etapa estou. | Acompanhamento da adesão | Média | A definir |
| HU04 | Como novo cliente, quero receber informações importantes sobre minha adesão por um canal acessível, para não perder atualizações relevantes. | Comunicação com o cliente | Média | A definir |
| HU05 | Como novo cliente, quero conferir meus dados de contato, para ajudar a garantir que as comunicações sejam enviadas corretamente. | Confirmação dos dados de contato | Média | A definir |
| HU06 | Como novo cliente, quero encontrar facilmente as informações da minha primeira fatura, para consultar valores, vencimento e pagamento quando precisar. | Acesso às informações da fatura | Alta | A definir |

## Critérios de aceite

### HU01 — Valor e vencimento
- [ ] O valor total deve estar claramente visível.
- [ ] A data de vencimento deve estar destacada.
- [ ] As informações devem ser apresentadas de forma organizada.

### HU02 — Instruções de pagamento
- [ ] As instruções de pagamento devem ser fáceis de localizar.
- [ ] O cliente deve conseguir compreender os passos para realizar o pagamento.

### HU03 — Acompanhamento da adesão
- [ ] O sistema deve apresentar as etapas do processo.
- [ ] A etapa atual deve estar identificada.

### HU04 — Comunicação
- [ ] O sistema deve apresentar informações importantes sobre a adesão.
- [ ] As mensagens devem ter conteúdo claro e objetivo.

### HU05 — Dados de contato
- [ ] O cliente deve conseguir visualizar os dados de contato cadastrados.
- [ ] O sistema deve indicar quais dados precisam ser conferidos.

### HU06 — Consulta da fatura
- [ ] O cliente deve conseguir localizar as informações da primeira fatura.
- [ ] O valor, o vencimento e as instruções de pagamento devem estar acessíveis.
- [ ] As telas devem funcionar adequadamente em dispositivos móveis.

**Observação:** as seis histórias são uma proposta inicial. A distribuição final deve ser combinada com o grupo, e hipóteses como problemas nos dados de contato precisam ser validadas, não tratadas como fatos comprovados.
